## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Campaign Tracker** | Track completion status across all Neverwinter module campaigns |
| **Boon Planner** | Log acquired boons and plan which campaigns to prioritize |
| **Daily Planner** | Organize your daily and weekly task checklist per character |
| **Character Log** | Track multiple characters across campaigns with separate profiles |
